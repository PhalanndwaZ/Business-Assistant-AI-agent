TROUBLESHOOTING
================================================================================

If something isn't working:

1. Check backend logs:
   • Look for "Connected to Neon PostgreSQL" message
   • Check for connection errors

2. Verify .env configuration:
   • USE_DATABASE=true
   • NEON_DATABASE_URL is set correctly
   • Connection string includes ?sslmode=require

3. Test connection:
   • Run: python scripts/test_database_connection.py

4. Switch back to JSON mode temporarily:
   • Set USE_DATABASE=false in .env
   • Restart backend

5. Check Neon status:
   • Visit https://neonstatus.com
   • Verify your project is active in Neon Console
